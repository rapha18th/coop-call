# Ziso API

The backend for Coop Call. The coop phone posts frames and sensor readings, Gemini turns frames into observations, Firestore keeps the timeline, and the owner's browser calls the coop through AssemblyAI's Voice Agent API.

Source: the `api/` folder of the Coop Call repository.
